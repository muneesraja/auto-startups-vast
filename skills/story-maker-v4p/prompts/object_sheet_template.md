Every plate, strap, edge, colour, material, and proportion stays exactly as described. Nothing is added, removed, restyled, or improved between panels. Backgrounds from any imagined photo are discarded — only the object is documented.

Layout — eight named panels on one 16:9 page (3840×2160). Two rows. Thin even gutters. Every panel a flat rectangle, square to camera, no tilt, no drop shadow, no overlap. No A-pose (this is an object, not a wearer).

TOP ROW — FOUR FULL VIEWS, equal panels, the whole object in each, same scale, same height, same camera distance, same even studio light. Only the angle changes:
1 - FRONT, facing the camera straight on
2 - THREE-QUARTER, turned 45 degrees
3 - SIDE, a STRICT profile at exactly 90 degrees, clearly different from panel 2
4 - BACK, seen from directly behind

BOTTOM ROW — FOUR CLOSE-UPS, equal panels, each a tight crop on a DIFFERENT identity-carrying part, each appearing ONCE:
5 - PRIMARY SURFACE / BODY of the object, filling the panel, no full-object repeat of the top row
6 - WORKING PART (blade, lid, spout, screen, mechanism — whichever carries function)
7 - GRIP / JOIN / FASTENER (handle, hinge, strap, seam)
8 - MATERIAL CLOSE-UP (texture, finish, emblem, wear) that does not repeat panels 5–7
